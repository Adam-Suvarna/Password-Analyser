About This Report

Each password was analysed against NIST SP 800-63B Revision 4 (August 2025), which emphasises password length over complexity, requires screening against breach databases, and prohibits commonly used passwords. Passwords were also checked against the HaveIBeenPwned database of over 1 billion compromised credentials using k-anonymity — no plaintext passwords were transmitted.
